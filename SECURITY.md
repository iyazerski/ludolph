# Security

Ludolph runs coding agents that can read and change files and run commands on your Mac. It can also link your Mac to a relay, so you can reach those agents from your phone. Please report anything that could let someone else control your agents or read your chats.

## Report a vulnerability

Report it privately through [GitHub's vulnerability reporting](https://github.com/iyazerski/ludolph/security/advisories/new). Please don't open a public issue.

Include what you found, how to reproduce it, and the Ludolph version. You'll get an answer within a week.

## Supported versions

Only the latest release gets fixes.
